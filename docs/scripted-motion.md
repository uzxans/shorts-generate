# Сценарный motion-режим

Запуск остаётся прежним, из любого каталога:

```sh
shorts 51
shorts 51,52
```

Команда читает `topics.json`. Если у темы есть `script_timeline`, используется новый сценарный рендер. Иначе — прежний генератор. Тема 41 не менялась. Темы 51–55 заменены на присланные CSS/UI-сюжеты; прежние записи сохранены в `docs/backups/topics-51-55-before-scripted-2026-09-18.json`.

Результат: `output/<id>_<название>-motion.mp4`, 1080×1920, 30fps, голос Дмитрий, динамическое выделение слов, музыка и исходная заставка `assets/frog.mp4` в конце на нормальной скорости. Заставка добавляет примерно 4.04 секунды к последнему `end`. Она не появляется внутри объяснения.

## Как задавать сценарий

```json
{
  "id": 101,
  "title": "Наклон карточки",
  "language": "css",
  "script_timeline": [
    {
      "start": 0,
      "end": 8,
      "scene_type": "tilt_card",
      "screen_text": "Наведение → наклон",
      "voiceover": "Наведи курсор — карточка наклонится. Убери — вернётся обратно.",
      "label": "CSS / HOVER",
      "note": "Угол наклона задан заранее",
      "animation": {"preset": "hover_tilt", "rotate_x": 10, "rotate_y": -15},
      "transition_out": {"type": "slide", "duration": 0.55}
    }
  ]
}
```

- `start/end`: числа в секундах, сцены идут подряд от нуля. Тайминг никогда не сжимается автоматически.
- `voiceover`: полный текст именно этой сцены. Многоточия и сокращённые куски сценария запрещены. Общий `voiceover` темы не используется новым рендером.
- `screen_text`: короткий заголовок; `label` — верхняя метка, `note` — пояснение под демонстрацией.
- `scene_type` и `animation.preset`: исполняемые команды из таблицы ниже.
- `transition_out`: переход к следующей сцене начинается на её `start`. Сцены перекрываются на время перехода, но речь и общая длительность не сдвигаются. Для последней сцены поле не применяется: далее исходная заставка.
- `visual/motion`: можно хранить как режиссёрские заметки, но свободный текст не превращается автоматически в произвольную анимацию. Рендер выполняет только явные поддерживаемые команды.
- `code`: для сцены с кодом; можно брать общий код темы. Показывайте короткие фрагменты, обычно до 12 строк по 40–45 символов. `highlights: [2,5]` — номера подсвечиваемых строк, начиная с 1.
- `points`: массив тезисов для `takeaway`, обычно три коротких пункта.

| scene_type | animation.preset | Демонстрация |
|---|---|---|
| title | reveal | Заголовок и наклоняющаяся карточка |
| perspective | depth | Перспектива и приближение карточки |
| tilt_card | hover_tilt / axes | Наведение и возврат / два направления поворота |
| code | code_focus | Появление строк и последовательная подсветка |
| gradient | angle_spin | Вращение цветного контура |
| bento | expand / jump | Плавное раскрытие / резкая смена для сравнения |
| spotlight | follow / float | Свет за курсором / карточка без подсветки |
| skeleton | crossfade / jump | Плавная / резкая смена заглушки контентом |
| takeaway | checklist | Последовательное появление итогов |

Переходы: `slide`, `crossfade`, `zoom`, `cut`. Дополнительные параметры анимации: `rotate_x`, `rotate_y`, `perspective`, `cycles` для соответствующих демонстраций. Для совершенно нового механизма нужно добавить новый визуальный пресет — ни название темы, ни произвольный HTML автоматически его не создают. `demo_html` в сценарном режиме не исполняется.

## Проверка и работа с голосом

```sh
shorts 51 --validate-script                 # только JSON и тайминг
shorts 51 --build-only                      # проект + озвучка, без кодирования MP4
shorts 51 --skip-voice --build-only         # быстрая немая проверка визуала
shorts 51 --max-duration 0                  # отключить лимит общей длительности
```

Голос генерируется по сценам. Кэш учитывает текст, голос и скорость. Слишком длинная реплика останавливает сборку с номером сцены: сократите текст или увеличьте интервал. Допускается только небольшое pitch-preserving выравнивание до 1.12× после синтеза +5%; речь не обрезается. Субтитры используют тайминги слов, а не равномерное распределение по длительности.

Для озвучки нужен интернет. Без доступа команда не выдаёт немой ролик за озвученный. `--skip-voice` — явный диагностический режим без звука, имя результата содержит `-silent`.

Редактируемые сборки лежат в `videos/scripted-<id>-<hash>/`. В них сохраняются `script.json`, `narration.json`, `captions.json`, `STORYBOARD.md`, `index.html` и локальные ассеты. Старые тематические проекты не перезаписываются. Новый MP4 заменяет предыдущий одноимённый результат только после успешного рендера и проверки длительности.

Зависимости закреплены в `package-lock.json`: HyperFrames/core 0.8.47. После переноса проекта: `npm ci`; также нужны существующий Python venv с edge-tts, Node и FFmpeg. Скрипт `tools/scripted_carve.mjs` взят из установленного HyperFrames Audio skill и делает частотное и динамическое освобождение места под речь.

## Технические источники сценариев

- Perspective / повороты: https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/perspective
- Typed custom properties: https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@property
- View transitions: https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API/Using

Сценарии не обещают гарантированное GPU-ускорение или нулевую стоимость перерисовки. Hover с фиксированным углом не выдаётся за слежение за мышью; spotlight явно включает передачу координат из JavaScript.
